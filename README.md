# ai-developer-yolculuk

AI Developer olma yolculuğumun günlüğü ve proje deposu. Fine-tuning'e atlamadan önce
sağlam bir temel (Python, veri, SQL, matematik sezgisi) kurup; sırasıyla LLM temelleri,
RAG, Agent'lar, fine-tuning ve production konularını proje bazlı öğreniyorum.

Tam müfredat: [AI_Developer_Komple_Mufredat.md](./AI_Developer_Komple_Mufredat.md)

## Fazlar

| Faz | Konu | Faz Projesi |
|---|---|---|
| 0 | Ortam + araç kurulumu | Çalışan geliştirme ortamı |
| 1 | Python (AI için gereken kısımlar) | Veri işleyen CLI aracı |
| 2 | Veri: numpy, pandas, görselleştirme | Veri analizi mini-raporu |
| 3 | SQL + veri modelleme | Sorgu portföyü + Python entegrasyonu |
| 4 | Matematik sezgisi | Elle embedding benzerlik hesabı |
| 5 | LLM temelleri + API + Prompt Engineering | Akıllı metin analiz aracı |
| 6 | Embedding + Vektör Veritabanları | Semantik arama motoru |
| 7 | RAG | Kendi dokümanlarınla konuşan asistan |
| 8 | AI Agents + Function Calling + MCP | Araç kullanan otonom agent |
| 9 | Fine-Tuning (LoRA/QLoRA) | Özelleştirilmiş küçük model |
| 10 | Evaluation, LLMOps, Deployment, Security | Canlıya alınmış RAG API'si |
| 11 | Bitirme projesi + portföy | Uçtan uca AI ürünü |

## Yapı

Her faz kendi klasöründe (`FAZ1/`, `FAZ2/`, ...), kendi çalışmalarını ve faz projesini
içerir. Her faz kendi git branch'inde geliştirilip PR ile `main`'e birleştirilir.
